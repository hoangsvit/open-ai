# ePlus ChatGPT Inspector

An **unofficial, read-only** promotion research toolkit for cataloging public ChatGPT offers, checking documented regional/partner restrictions, and distinguishing expired programs from outdated evidence. Android app detection (ADB) is an optional diagnostic, unrelated to offer eligibility.

> **Disclaimer:** This project is not affiliated with OpenAI, Google or Apple. It cannot verify your account's plan, entitlement, eligibility, purchases or renewal date. It never collects tokens, account credentials, payment data or starts a subscription checkout.

## Features

- **Detect Android app:** checks package `com.openai.chatgpt` with ADB, shows version if available, and does not print device serials.
- **Manage subscription:** provides official management pages for web, Google Play and Apple, opened only after explicit user action.
- **Explore promotions:** shows official terms for verified public programs with eligibility warnings, including a U.S.-targeted veteran benefit, Codex credits, ChatGPT for Teachers, Revolut Go trial benefits and archived India/Shopee/Free-referral programs. These are different benefit types, not all Plus subscriptions. Source dates must be manually rechecked; no invented codes or account guarantees.
- **Optional Textual dashboard:** simple, readable navigation with status details.

MuMuPlayer, root, Frida and an emulator are **not required** for the information features. Android inspection needs the [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) and an authorized connected device/emulator.

## Installation

Requires Python 3.10 or newer. On Windows PowerShell:

```powershell
git clone https://github.com/hoangsvit/open-ai.git
cd open-ai
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[tui]"
.\.venv\Scripts\open-ai-inspector.exe
```

On Linux/macOS use `python3 -m venv .venv` and `.venv/bin/python -m pip install -e ".[tui]"`. The CLI has no required third-party dependencies: `python -m pip install -e .`.

```powershell
python -m open_ai_inspector tui
```

The TUI launches by default on **Explore offers** without requiring ADB. Android app inspection is optional (button or **R**). Press **Q** to exit.

The ADB inspector executes only `adb devices`, `adb shell pm path com.openai.chatgpt` and `adb shell dumpsys package com.openai.chatgpt`. It cannot determine if ChatGPT Plus/Go/Pro is activated.

## Curating promotions

`src/open_ai_inspector/data/official.json` stores manually researched official terms, claim links, eligibility restrictions and archived programs. A claim deadline of `null` means **not published**, not an unlimited active offer. Optional local files can be loaded via `promos --catalog path/to/file.json`. An offer must have an approved OpenAI or vetted partner HTTPS source, eligibility/region description, review date and a claim deadline when published. Unknown claim deadlines stay null. Claim windows that have ended are marked **expired**; otherwise, sources not reviewed for over 30 days are labeled **needs_reverification**, not expired. Both are hidden from the default current list and available with `--include-archived` (old alias `--include-expired` still works). JSON output omits archived records unless this flag is requested.

**Important:** Listing a public promotion never establishes eligibility for a particular account. No promo code or subscription extension is generated by this toolkit.

### Regional trials and partner programs

The catalog now distinguishes subscription trials, paid-plan benefits, paid continuation discounts, Free usage-limit increases, Codex credits and education plans. **These benefits are not interchangeable.**

- **India Go 12-month free year:** registration ended **2026-01-21**; paid, targeted continuation discounts do not restart the free year.
- **ShopeeVIP Vietnam Go 3 months:** registration ended **2026-05-31**.
- **Revolut Standard/Plus Go 3-month trial:** the published campaign runs through **2027-07-29**, for invited eligible customers only. Automatic paid renewal may follow.
- **Revolut Premium/Metal/Ultra benefits:** 6–12 months of Go may be included with eligible **paid Revolut plans**, subject to country and account conditions.
- **ChatGPT Free referral boost:** ended **2026-09-17**, doubled usage limits rather than granting Plus or Go.

Only exact approved official partner domains are accepted as evidence. Redemptions are not generated; see [partner sources and eligibility details](docs/OFFER-DISCOVERY.md).

## Automatic offer discovery

GitHub Actions checks official public OpenAI pages every **6 hours** and proposes newly linked ChatGPT promotion pages as **pending-review leads** in a Draft PR. It never publishes a link as a verified, redeemable promotion on its own. A reviewer must validate the terms, region, end date, eligibility and applicable charges.

Run discovery manually with `python scripts/discover_offers.py`. Discovery fails closed when no source provides parseable links, and warns if a source contains no promotion-like public articles. OpenAI/Help Center may change markup or render results in JavaScript, so a successful CI test is **not** proof the scheduled crawler found a real offer. It does not fetch account offers, email, cookies, payment data or use undocumented APIs.

See [Offer discovery design and limitations](docs/OFFER-DISCOVERY.md).
